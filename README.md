# 岩芯样本切片实验室 · 制片交接

运行：

```bash
npm start        # http://localhost:3025
npm test         # 交接判定层单元测试
```

## 制片交接流程

每张切片按 **取样 → 切割 → 研磨 → 染色** 逐道交接，每道交接单记录：

- 操作人（本班完成人）、拟交复核人
- 耗材批次（染色工序必须使用在有效期内的染色批次）
- 观察结果
- 交接时间（实际完成时间）

规则：

1. 上一道没有复核通过，不能交接下一道（首道“取样”无前序校验）。
2. 交接提交后进入“待复核”，同一道未出复核结论不能再次交接。
3. 复核不通过：退回当前步骤，必须填写退回原因，责任人切回操作人；重做后重新送复核，历史交接与退回记录全部留痕。
4. 复核通过：放行到下一道；染色复核通过后整片完成。
5. 以下冲突本次交接 **不保存**，接口返回 409 并逐条指出冲突项：
   - 染色批次在交接时间点已过期（或批次未登记）；
   - 交接时间早于上一步复核通过交接单的完成时间；
   - 操作人 / 耗材批次 / 观察结果 / 交接时间缺失或无效；
   - 上一步未复核、待复核中重复交接、工序与当前步骤不符。
6. 全部切片完成染色复核后样本才允许标记交付。

样本列表可看到：当前责任人（待交接时为操作人、待复核时为复核人、退回时为原操作人）、最近一次复核结果与退回原因、四道工序流转状态，以及“交接 / 复核”可操作入口（按状态启用或禁用）。

## 分层

- `server.js`：请求入口，只做 HTTP 收参、状态码与路由。
- `src/handoff.js`：交接判定（纯函数，无 IO）与状态流转、列表视图派生。
- `src/repository.js`：保存层，负责 JSON 文件读写、种子数据与旧版 logs 数据迁移。
- `public/index.html`：页面与交互弹窗。

## API

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/samples` | 样本列表（含当前责任人、最近复核、操作入口视图） |
| POST | `/api/samples` | 创建样本（含初始切片） |
| POST | `/api/samples/:id/slices` | 新增切片 |
| GET | `/api/reagent-batches` | 耗材/染色批次及有效期 |
| POST | `/api/samples/:id/slices/:sid/handoffs` | 提交交接（判定不通过返回 409，不落盘） |
| POST | `/api/samples/:id/slices/:sid/reviews` | 复核（通过放行 / 不通过退回并记原因） |
| POST | `/api/samples/:id/deliver` | 全部完成后交付 |
